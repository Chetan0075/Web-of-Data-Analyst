# ⏳ CRX Time Game Portfolio

An interactive Data Analyst portfolio website that transforms a traditional portfolio into a gamified experience.

Users enter their date of birth and unlock projects based on the number of days they have lived. Built with React, Tailwind CSS, and dynamic analytics visualizations.
